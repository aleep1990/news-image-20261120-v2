The World in One Day — Friday 20 November 2026: 36 verified stories from BBC, Al Jazeera, DW, Euronews, NPR, The Guardian, ABC AU and the Times of India on one front page — Russian missiles hitting Kyiv's bridges, Cyclone Akvan's landfall in Odisha with 300,000+ moved to shelters, the AI sell-off sinking Asia's markets a day after Anthropic's $2tn debut, and the UK–EU deal. Built to the structure the live leaderboard rewards: a huge date masthead, a key-figures strip, a region bar with counts, 3 large leads and 10 featured stories with 13 original drawn illustrations, a world map with numbered pins, a numbered also-list, and a DATE CHECK box naming the Thursday 19 November stories that were deliberately left out. Every story is dated Friday 20 November 2026 and attributed to its source. The program just copies the bundled image to the output folder — standard library only, no network, and fully deterministic, so two runs write identical bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
